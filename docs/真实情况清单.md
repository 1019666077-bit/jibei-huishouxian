# 原创设定与实现边界

## 世界观

极夜灾变切断了北方科研带的能源与通信。北辰回收署派出单人技术回收员进入废弃极地气候研究城，在灰潮守备队完成封城前，回收气候预测、能源调度与极光观测资产。配给点是回收署内部用于衡量装备投入和技术资产贡献的结算单位，不对应现实货币。

外围四区为冻港仓储区、气象塔群、热能管廊和轨道升降场。内环六房为冷却舱、磁悬舱、压缩机房、暗光仓、风暴庭院和潮汐坞。极光指挥塔保存零号资产柜，是单局最高价值终点。

灰潮守备队包括巡检兵、强化巡检组、重甲护卫、盾卫、热焰手、机枪手、履带哨机和侦察蜂。三名原创指挥官分别是升降场的白獠、风暴庭院的霜鸦和潮汐坞的沉锚。

## 已实现

- 八个原创出生点与基于新地理的出生动线。
- 外围双环邻接和内环折线加庭院捷径拓扑。
- 69 个事件对象，包含阶段变体、状态门禁、入口节点与唯一资产。
- 每个内环房间至少四个事件，事件只在相邻房间之间流转。
- 35 种原创技术资产及六档品质。
- 原创枪械与弹药显示名，保留口径、穿深、发数、护板和跳弹机制。
- 三档装备投入、配给点仓库、失败损失、成功返还和消耗品结算。
- 双配电柄与极地索道窗口。
- 极地索道、风暴列车、借用索道窗口、接管撤收吊舱、货运雪橇五种撤收方式。
- 绝密资产图鉴、赛季战绩、行动章、战报和针对性重开建议。
- 暴风演算主机的定位脉冲会实际提高后续遭遇概率。

## 当前抽象

- 角色只有统一生命值，没有身体部位、流血或骨折状态。
- 医疗被抽象为统一模块，没有细分止血、手术和镇痛用品。
- 玩家以单人文字决策推进，没有实时移动、瞄准或组队救援。
- 物品按格数管理，不模拟形状旋转。
- 配给点估值为静态表，不存在用户之间的交易。
- 极夜天气主要体现在事件、风险和地图表达中，没有独立温度条。
- 首版只提供本地单机存档，不包含开发者云账号、排行榜、邀请归因或共享战报。

## 原创内容守则

新增内容必须使用北辰回收署、灰潮守备队和极地气候研究城体系。枪械使用虚构型号或通用等级；物资以气候研究、能源、运输和观测技术为来源；地图名称需与现有四区六房拓扑一致。不得引入其他作品的角色、地图、专有物品、口号、玩家黑话或对照说明。
