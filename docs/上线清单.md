# 极夜回收线 IAA 上线清单

本页是开发侧速查，正式法务门禁以 `compliance/submission-checklist.md` 为准。

## 当前发行边界

- 原生微信小游戏 Canvas 2D，不是普通小程序。
- IAA 广告模式，当前及未来均不开通虚拟支付。
- 首版本地单机：不登录、不取得 OpenID、不上传战绩，不提供排行榜、邀请奖励或共享战报。
- 分享完全自愿且无奖励。
- 激励视频仅提供每日一次固定医疗补给，不影响随机掉落。

## 代码门禁

1. `project.config.json` 的 `compileType` 必须为 `minigame`，以 `game.js/game.json` 启动。
2. 发布目录不得存在 Page/WXML/WXSS/WXS、云登录、OpenID、邀请归因、行为分析或支付入口。
3. `cd test && npm test` 必须全绿；其中 `npm run legal` 负责第三方识别词和发行边界扫描。
4. 内容保持 68 个事件、30 种物品、8 个出生点、四区六房和五种撤收方式，全部使用原创表达。
5. 真机覆盖首启协议、同意/拒绝、触摸滚动、完整行动、成功/失败结算、仓库、图鉴、重开和一键清档。

## 广告门禁

1. 广告必须由用户主动点击，播放前明确“完整观看后获得 1 份医疗补给，每日一次”。
2. 仅 `res.isEnded === true` 发奖；提前关闭、加载失败和存储失败均不发奖，也不扣已有权益。
3. 奖励固定，不提高绝密资产概率，不保留失败资产，不锁定基础玩法。
4. `adUnitId` 为空时入口隐藏；正式广告单元只能在微信流量主后台创建后填入。

## 主体必须完成的外部事项

1. 用正式小游戏 AppID 替换 `touristappid`。
2. 完成正式名称第 9、41、42 类商标近似检索；公开网页搜索不能替代中国商标网检索。
3. 完成软件著作权和作者/外包成果归属材料。
4. 走微信 IAA 资质审核、小游戏前置备案和工信部小程序备案，并取得属地主管部门及微信对适用路径的确认。
5. 在微信后台配置与实际代码一致的《用户隐私保护指引》。
6. 完成适龄提示审核，并确认腾讯健康系统及中宣部实名认证防沉迷接入状态。
7. 填写运营主体、客服、权利投诉和未成年人保护联系方式；不得携带占位符提交。

## 已知边界

- 仓库、图鉴、赛季、战报和协议确认只存在本机，清缓存或换设备会丢失。
- 配给点和物品不具备现实价值，不可交易、提现或转让。
- 未配置广告时游戏仍可完整游玩。
- 外部备案、软著、适龄审核和平台审批不由代码自动完成。
