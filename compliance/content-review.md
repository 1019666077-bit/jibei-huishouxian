## 自动门禁

- `npm run legal`：第三方识别词、误导宣传、邀请奖励、OpenID/云调用、支付入口和普通小程序页面残留为 0。
- `npm run routes`：事件引用、地图邻接、条件谓词和物品引用合法。
- `npm run content`：阶段与状态变体可达，内容机制不产生死节点。
- `npm run audit`：事件数量、区域分布和重复度达标。
- `npm test`：全部玩法、经济和随机不变量回归通过。

## 人工逐条审校标准

每个事件必须同时满足：

1. 从“北辰回收署进入极夜灾变后的废弃气候研究城”原创设定出发，不是第三方游戏事件的同义替换。
2. 人物、组织、地名、物品、黑话、路线和数值不产生第三方游戏来源联想。
3. 不含写实血腥、肢解、虐待、自伤教学或美化现实暴力的细节。
4. 不含赌博、押注、现金红包、提现、现实物品交易或付费随机承诺。
5. 不含侮辱、歧视、低俗、极端主义、违法犯罪教学或违背公序良俗的内容。
6. 选项结果与文案一致，不作“必得、最高、实时、官方、正版”等无法证明的承诺。
7. 适龄强度与最终平台适龄结果一致。
