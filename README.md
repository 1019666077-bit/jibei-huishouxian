# 极夜回收线

《极夜回收线》是一款原创文字决策撤收小游戏。极夜灾变后，北辰回收署进入废弃的极地气候研究城，赶在灰潮守备队封城前回收气候技术资产。玩家需要在伤势、负重、弹药、护板、风险与配给点投入之间取舍，最终从南侧撤收线带出资产。

项目使用原生微信小游戏 Canvas 2D 运行时。单局引擎、物资系统和局外仓库均为纯 JavaScript。首版固定为本地 IAA：不建立开发者账号、不取得 OpenID、不上传战绩、不提供排行榜或共享战报，也不包含虚拟支付。

## 原创地图

外围四区是冻港仓储区、气象塔群、热能管廊和轨道升降场。研究城内环由冷却舱、磁悬舱、压缩机房、暗光仓、风暴庭院和潮汐坞组成，高价值终点是极光指挥塔。

外围采用双环联络线：冻港连接热能管廊与轨道升降场，气象塔群连接热能管廊与轨道升降场。内环采用折线结构：冷却舱—磁悬舱—暗光仓—压缩机房—潮汐坞，风暴庭院提供连接六房的高风险捷径。事件只在当前区、相邻区或明确的 `goEvent` 目标出现。

八个出生点分别位于西侧测风门、冻港西堤、冷库屋顶、上层风标平台、热能管廊北端、二号热能支站、供能沟底部和轨道下层平台。不同出生点会给出不同的通行芯片路线、低风险搜刮线和首轮交火线。

## 核心机制

- 三档装备投入：重装回收组 45 万配给点、标准勤务组 15 万配给点、轻装勘探组零投入。
- 装备投入在进场时冻结；成功撤收会返还装备成本，只结算弹药、医疗和通行芯片消耗；失败则损失本轮装备。
- 弹药使用原创型号，保留口径、穿深与发数机制。穿深不足会产生跳弹、降低判定并增加耗弹。
- 共 30 种原创物品，分为六档品质。绝密资产包括北辰零号晶核、相控云图阵列、暴风演算主机、地热引燃剂和百年气候母盘等。
- 暴风演算主机是唯一指定资产：携带后会广播定位脉冲，使后续遭遇概率上升。
- 冷却舱与压缩机房各有一处常驻配电柄；双电源接通后开启极地索道撤收窗口。
- 五种撤收方式：极地索道、风暴列车、借用他队索道窗口、接管撤收吊舱、货运雪橇。货运雪橇最稳，但只保留低温回收匣内物资。
- 结算提供行动评级、配给点收益、路线、战果、资源消耗、关键时刻与两条针对性重开建议。
- 原创行动章包括归航标、零号见证、逆向接管、断潮者、极夜清道夫、满载归署、脉冲负重者、轻装破局和全线踏查。

## 数据结构

`miniprogram/data/events.js` 聚合全部事件。`events/map.js` 定义区域邻接、内环房间拓扑和热点人流；`spawns.js` 定义八个出生点；`outer.js`、`core.js`、`aurora.js` 合计提供 68 个事件对象，其中 4 个是内环入口抉择。

事件保留 `zone`、`room`、`phase`、`when`、`entryOnly`、`free`、`options`、`success` 和 `fail` 等字段。`effects` 通过选项中的效果对象表达；路线引用依靠稳定 ID 连接。

## 目录

- `miniprogram/game.js`、`game.json`：微信小游戏入口和运行配置。
- `miniprogram/runtime/`：Canvas 绘制、场景切换、触摸命中和滚动。
- `miniprogram/scenes/`：大厅、行动、结算、图鉴、设置和协议场景。
- `miniprogram/data/`：物资、弹药、地图与 68 个事件。
- `miniprogram/core/engine.js`：单局状态、判定、拾取、撤收和战报。
- `miniprogram/core/meta.js`：配给点仓库、绝密资产图鉴和赛季本地存档。
- `miniprogram/legal/`：游戏内用户协议、隐私与未成年人说明。
- `miniprogram/utils/ads.js`：每日一次、固定医疗奖励的激励视频封装。
- `compliance/`：软著、IAA 前置备案、权属和内容审校材料底稿。
- `test/`：法务门禁、Canvas 运行时、路线、内容、经济和随机对局回归。

## 本地验证

在 `test` 目录运行：

```powershell
cd test
npm test
```

如仅验证事件结构，可运行测试包中的路线、内容和审计脚本。经济数值有调整时，应额外执行经济模拟。

## IAA 上线方向

激励视频只有一个用途：用户主动完整观看后领取一份固定医疗补给，每日最多一次。它不改变随机掉落、不保留失败资产、不锁定基础玩法；未配置 `adUnitId` 时入口完全隐藏。

上线前仍需由运营主体完成 AppID、广告单元、正式名称商标检索、软件著作权、IAA 小游戏前置备案、工信部小程序备案、适龄提示、实名防沉迷确认和真机联调。详细门禁见 `compliance/submission-checklist.md`。
